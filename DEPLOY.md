# Publish PreShift on GitHub Pages

1. Open https://github.com/aryantiwari1118/PreShift
2. Click **Add file → Upload files**.
3. Upload `index.html`, `style.css`, `robots.txt`, `sitemap.xml`, and `.nojekyll` to the repository root.
4. Commit the files to `main`.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, select **Deploy from a branch**.
7. Select branch `main`, folder `/(root)`, then **Save**.
8. Wait for deployment, then visit https://aryantiwari1118.github.io/PreShift/

## Google Search Console
1. Open https://search.google.com/search-console/
2. Add a URL-prefix property for `https://aryantiwari1118.github.io/PreShift/`.
3. Complete the verification method offered by Google.
4. Use **URL Inspection** for the homepage and click **Request indexing** if available.
5. Submit `https://aryantiwari1118.github.io/PreShift/sitemap.xml` in **Sitemaps**, if accepted.

Publishing does not guarantee or immediately produce Google indexing. The canonical URL and sitemap assume this exact GitHub Pages URL. Update these files if you change the username, repository name, or domain.
